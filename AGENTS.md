# AGENTS.md

Shared operating rules for agents working in this vault. Keep personal context and task-specific procedures in their authoritative files, not here.

## Context

Read only what the task requires:

- `0 - System/me.md` — identity and working preferences.
- `0 - System/vault-map.md` — locations, permissions, and output routing.
- `0 - System/skills-index.md` and the active skill catalog — workflows and triggers.
- `0 - System/memories/` — persistent context, where relevant.

Load the relevant skill before acting. Follow its references for writing, formatting, and technical procedures. If no skill applies, use general judgment. Reference existing sources rather than duplicating them.

## Boundaries

- The private folder (including the journal) is off limits: never access, list, scan, modify, reference, index, remember, or transmit its contents.
- Privacy is folder-based: every private file lives in the private folder.
- Search only permitted locations; do not scan the whole vault or follow links into protected areas.
- Local processing, tools, and conflicting documents never waive privacy restrictions. Sensitive permitted content must remain local.
- Work within the request and established permissions. Review or advice is not authorization to edit.
- Change system configuration or agent instructions only when explicitly requested. Routine maintenance stays within its designated scope.
- Preserve user content, raw sources, and task history unless the requested change explicitly covers them. Edit authoritative sources, not generated copies.

## Execution

- Check prerequisites and relevant context before acting.
- Verify current state rather than assuming saved information is current.
- Do not invent facts, intentions, actions, or results.
- Verify the requested outcome before claiming completion; report blockers and partial completion clearly.
- Keep reusable procedures in skills and temporary progress in session context, not permanent memory.
